# Equirectangular → Cubemap conversion formulas

В проекте используется стандартное преобразование из эквиректангулярной проекции в 6 граней куба.

## 1) Нормализация координат пикселя на грани

Для пикселя `(x, y)` на грани размера `N × N`:

- `u = 2 * (x + 0.5) / N - 1`
- `v = 2 * (y + 0.5) / N - 1`

Где `u, v ∈ [-1, 1]`.

## 2) Выбор направления для каждой грани

Используются направления `(dx, dy, dz)`:

- Right  (+X): `( 1,  v, -u)`
- Left   (-X): `(-1,  v,  u)`
- Top    (+Y): `( u,  1, -v)`
- Bottom (-Y): `( u, -1,  v)`
- Front  (+Z): `( u,  v,  1)`
- Back   (-Z): `(-u,  v, -1)`

Далее вектор нормализуется:

- `n = (nx, ny, nz) = (dx, dy, dz) / sqrt(dx² + dy² + dz²)`

## 3) Переход к сферическим углам

- `theta = atan2(nx, nz)` — азимут (`[-π, π]`)
- `phi = asin(ny)` — высота (`[-π/2, π/2]`)

## 4) Переход к координатам исходного эквиректангулярного кадра

Для исходного кадра размера `W × H`:

- `srcX = (theta + π) / (2π) * W`
- `srcY = (π/2 - phi) / π * H`

Эти `srcX/srcY` используются в `remap(...)` для семплирования исходного изображения.
